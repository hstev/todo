# Hoy

Lista de tareas del día, con medición de tiempo y archivo automático a medianoche. Todo vive en `localStorage`.

```bash
nvm use
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173). Requiere Node 18 o superior.

- **Enter** crea una tarea desde la última fila
- Sin confirmar al borrar: van a **Eliminados** y se pueden restaurar
- **Play** abre la tarea en primer plano y cuenta el tiempo
- En **Ajustes**: nombre, reinicio diario y tema
- En **Datos**: historial, estados, metadatos y export JSON
